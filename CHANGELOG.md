# Changelog - Stellar Splash Frontend

All notable changes to `stellar-splash-frontend` are documented in this file.

## [1.0.0] - 2026-10-29

### Added
- **Multi-Wallet Adapter**: Full support for Freighter, Lobstr, xBull, and instant sandbox judge demo mode.
- **Interactive Replay Scrubber**: Frame-by-frame physics playback and velocity vector inspector.
- **Dynamic Payout Donut Chart**: Real-time visualization of 10,000 basis points prize splits.
- **Tournament Creation Wizard**: 4-step wizard for organizing custom prize pools with creator royalties.
- **Procedural Web Audio**: Zero-asset retro synthesizer for retro arcade sound effects.
- **Virtual Mobile Joystick**: Responsive touch overlay for mobile gaming.
- **Solvency & Reserve Audit Modal**: Real-time on-chain vault solvency auditor against live liabilities.
- **Friendbot 1-Click Onboarder**: Direct testnet XLM faucet integration.
- **Production CI/CD**: Lighthouse CI, bundle size budgets, Dockerfile, Nginx SPA config, and a11y linters.
- **Client SDK**: `@stellar-splash/client-sdk` for third-party games, bots, and analytics tools.
- **Judge Materials**: 5-minute evaluation guide, cheatsheet, pitch deck, and architecture diagrams.
